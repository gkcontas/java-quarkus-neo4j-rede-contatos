# Rede de Contatos

Modelagem de um grafo de relacionamentos (pessoas e conexões) em Java com Quarkus e Neo4j, expondo consultas típicas de grafo (conexões diretas, caminhos entre pessoas, sugestões) via API REST.

## Stack

- Java + Quarkus
- Neo4j (driver oficial / Quarkus Neo4j extension)
- Testcontainers (testes de integração)
